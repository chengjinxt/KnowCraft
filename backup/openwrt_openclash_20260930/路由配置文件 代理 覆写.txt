- 在 Windows 下直接使用内置的 OpenSSH 客户端。

- 在 `C:\Users\<你的用户名>\.ssh\config` 中配置路由器的免密别名：

  代码段

  ```
  Host openwrt
      HostName 192.168.100.1
      User root
      Port 22
  ```

- 打开终端直接敲 `ssh openwrt` 即可秒连。
