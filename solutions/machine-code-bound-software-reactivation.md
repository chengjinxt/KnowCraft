# 机器码绑定软件换机后无法进入的重新开通方法

> 本记录已脱敏：不含任何个人机器码、账号、购买邮箱、安装路径、订单号或卖家联系方式。需要填入的信息请只在给卖家的私信里提供，不要公开。

## 一句话结论

这类软件是按机器码绑定的：电脑信息一变，旧注册码就对不上新机器码了，软件会回到“尚未注册”界面。这不是资源文件丢了，也不是重装能修好的；正确做法是拿着新机器码找原卖家重新开通，拿到新注册码再填回去。

## 它是什么

- 机器码（Machine Code，机器标识码）：软件根据当前电脑的硬件信息算出来的一串标识，用来认“这是哪台电脑”。
- 注册码（Registration Code，授权码）：卖家根据你这台电脑的机器码和用户名生成的授权；它只对生成时那台机器有效。
- 用户名：这类软件通常默认用购买时登记的邮箱作为用户名，注册时用户名和注册码必须成对填写，不能只填一个。

## 为什么换了电脑信息就进不去

白话说：旧注册码是按旧电脑的“身份证”发的，电脑信息变了等于换了身份证，旧证自然验不过。

准确一点说：机器码随硬件信息变化而变化；注册校验会把当前机器码和注册码重新比对，比对不上就拒绝进入主界面，回到注册框。本地的学习资源文件本身通常还在，只是被注册校验挡在外面，所以不要因为进不去就删目录、重装或格式化，那样既修不好注册，还可能丢数据。

## 重新开通步骤

1. 打开软件，进入注册界面，完整复制当前显示的新机器码，先自己保存一份，不要截图公开发到群里。
2. 找出当年的购买记录：购买平台的订单、和卖家的聊天记录、付款记录，确认两点：当时登记的邮箱（用户名），以及卖家的联系渠道。
3. 给卖家发一条私信，内容只给这四样：当年购买证明、登记邮箱、当前新机器码、说明“电脑信息变更后旧注册码失效，请求重新绑定/发新注册码”。同时问清两点：重新绑定是否收费、是否有次数限制。
4. 收到新注册码后，在注册界面按原样填写用户名和注册码，注意不要多空格、不要把字母和数字看错，点注册后重启软件一次，确认能正常进入并看到原有内容。
5. 如果卖家联系不上，先回到原购买平台的订单页找卖家入口或平台客服申诉；不要在网上搜“注册机”“破解补丁”，那既可能带病毒，也会让正版授权彻底作废。

## 容易误解的地方

- 旧注册码不是“过期了”，是“不对号了”：换回旧电脑信息理论上可能恢复，但改硬件、换主板、重装系统后往往无法精确还原，不要为此折腾硬件。
- 重装软件不会生成新授权：新机器码还是同一台电脑算出来的，旧注册码依然对不上。
- 只换用户名或只换注册码都不行：用户名和注册码是卖家成对生成的，必须一起填对。

## 下次换电脑前

- 先问卖家：支不支持解绑/迁移、有没有次数限制。
- 换机前把购买记录、登记邮箱、旧机器码（私下保存）记下来，换机后第一时间按上面第 3 步找卖家重新绑定。
- 购买记录和机器码属于个人标识，只保存在私人笔记里，不要放进公开的知识库或公开帖子。
