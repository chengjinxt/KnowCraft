# ImageGen 最终提示词摘要

三张卡片均使用 Codex 内置 `imagegen` 生成，分类为 `scientific-educational`。共同视觉要求：原创中文信息图、`3:4` 竖版、完全不透明浅米白背景、深海军蓝标题、青绿色结论块、橙色风险块、圆角布局和少量路由器图标；不显示真实 Logo、IP、MAC、SSID、账号、密码、二维码或水印。

## 01 — 运行 Mihomo 的四个条件

核心文字：

```text
路由器能跑 Mihomo，先看这 4 点
① 系统能换：能安装 OpenWrt 类固件
② 架构匹配：Mihomo 必须有对应 CPU 架构的 Linux 核心
③ 资源够用：256 MB 内存可入门，512 MB 更从容
④ 能恢复：确认 U-Boot、TFTP 或串口救砖路径
普通 PPTP / VPN 页面不能直接填写 Clash 订阅
OpenClash：路由器端管理插件
Mihomo：真正执行代理与分流的核心
```

## 02 — 原厂未刷与已刷二手

核心文字：

```text
原厂未刷 vs 已刷二手，怎么选？
原厂未刷：来源较清楚，可自己选择系统；但新固件可能堵住提权入口，同名型号也可能存在批次差异
已刷第三方固件：可验证启动与网口；但需要检查固件来源、原厂分区、校准数据、密码和分区布局
更适合自己刷的买法：原厂系统 + 准确型号 + 可复现教程 + 明确救砖方式
未刷只是状态，不是安全认证；价格也不一定比已刷机便宜
```

## 03 — 二手挂牌价比较

核心文字：

```text
二手路由器，别只看最低价
约 ¥30–60：支持不明、较旧或冷门型号
约 ¥80–85：CR6609 已刷
约 ¥95–105：360T7 已刷
约 ¥120–155：RAX3000M / Me 已刷
另有约 ¥185–190 的 RAX3000M 原厂未刷 / 全新挂牌
真实总成本 = 机器价格 + 电源与运费 + 转串口工具 + 时间成本 + 救砖风险
```

约束：必须明确数字来自用户提供截图中的挂牌样本，不能写成全网行情或最终成交价。
