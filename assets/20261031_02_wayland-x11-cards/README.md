# Wayland 和 X11 有什么不一样

面向完全不懂显示协议的读者：先讲结论和实际作用，再补必要的技术边界，不堆术语。术语第一次出现时同时给出英文全称和中文解释。

## 术语表

- 显示服务器（Display Server）：程序和屏幕之间的中间层，负责把各程序的画面安排上屏幕，并把鼠标、键盘输入传回程序。
- X11（X Window System，X 窗口系统）：老牌显示协议。X 计划始于 1984 年，X11 版本于 1987 年发布；卡片上写 1984 年是按计划起始年简化。
- 客户端/服务器（Client/Server）：X11 的架构分工，程序是客户端，显示服务器管屏幕，两边用协议说话。
- 网络透明：X11 的特性，程序可以在一台机器上跑、画面显示在另一台机器上。
- 合成器（Compositor）：把各程序的画面合成为最终屏幕画面的组件。Wayland 下合成器就是显示服务器本身；X11 下合成器是外挂的。
- Wayland（Wayland 显示协议）：新一代显示协议，2008 年立项，1.0 版 2012 年发布；卡片上写 2008 年是按立项年简化。
- XWayland（XWayland 兼容层）：让 X11 程序在 Wayland 下运行的翻译层。
- RealVNC Server（RealVNC 远程桌面服务端）：老牌远程桌面服务端，只支持 X11。
- wayvnc（Wayland 远程桌面）：Wayland 下的远程桌面服务端，讲标准远程桌面协议，Viewer 客户端照常用。
- Raspberry Pi Connect（树莓派连接服务）：树莓派官方的云端远程服务，屏幕共享需要 Wayland 会话。
- labwc（Wayland 合成器）：轻量 Wayland 合成器，树莓派新系统 Trixie 在 Pi 3 上的实际桌面。
- `raspi-config`：树莓派官方系统配置工具，它的 VNC 开关会按桌面类型自动选服务端：X11 下装 RealVNC，Wayland 下开 wayvnc。
- Trixie：树莓派官方系统的新版本（Debian 13 一代）。
- Chromium：开源浏览器，树莓派官方系统自带。

## 逐卡详解

1. 什么是显示服务器：没有它，多个程序会抢着往同一块屏幕上画。显示服务器统一排位置、收输入，是“一块屏幕多人用”的前提。
2. X11，老牌显示协议：诞生在网络时代，设计目标是通用和跨机器显示，所以协议庞大、什么都想管。
3. X11 的老毛病：画面撕裂是因为老架构下程序和显卡各画各的，合成时机对不上；隔离差是因为 X11 协议默认允许客户端读取全局输入和别的窗口内容；现代效果（阴影、透明、动画）要靠外挂合成器补，越补越复杂。
4. Wayland，新一代协议：只保留核心，把窗口管理、合成这些事收进合成器，协议本身变简单。
5. Wayland 好在哪：合成器统一上屏所以每帧完整；程序只能拿到自己的输入和画面所以更安全；架构简单所以更省资源；触屏、手势是原生设计。
6. 老程序怎么办：XWayland 把 X11 请求翻译给 Wayland 合成器，大部分老程序不用改就能跑；极少数依赖 X11 老特性（比如全局按键监听、特殊窗口操作）的程序可能有小毛病，要个案确认。
7. 远程桌面怎么变：服务端换了，客户端不用换。RealVNC Viewer 连 wayvnc 照常用；`raspi-config` 的 VNC 开关按桌面类型自动选；Raspberry Pi Connect 的屏幕共享需要 Wayland 会话。
8. 对学习机意味着什么：新系统 Trixie + labwc 就是 Wayland 桌面；Chromium 在 Wayland 下原生运行，不用兼容层；开机自启要按 labwc 的方式写（`~/.config/labwc/autostart`），不能照搬老系统的写法；远程桌面照常用 Viewer 连，开发验收不受影响。

## 适用前提与边界

- 本套卡面向树莓派官方系统用户；远程桌面结论针对官方系统的 `raspi-config` 行为，其他发行版的服务端选择可能不同。
- “Pi 3 在 Trixie 下跑 labwc（Wayland）”是本机实测结论：此前“Pi 3 默认 X11”的说法已在本机上被纠正，不要再按 X11 去写自启。
- Raspberry Pi Connect 本人未在本机实测开通，这里只说明它的屏幕共享需要 Wayland 会话这一前提。

## 常见误解

- “换 Wayland，老软件全不能用”：不对，XWayland 会翻译，大部分老程序照常用。
- “RealVNC 不能用，远程桌面就断了”：不对，只是服务端从 RealVNC Server 换成 wayvnc，Viewer 客户端不用换。
- “Wayland 和 X11 能同时装、随便切”：桌面会话一次只能跑一种，切换要注销重进另一会话，不是两个叠加跑。
