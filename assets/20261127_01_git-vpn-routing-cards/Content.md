# Git 拉取流量走哪儿

拉代码时，不是哪个 VPN 先启动就走哪个。先看远程地址：SSH 通常交给系统路由；HTTPS 是否经过代理，主要看 Git 的代理配置。

FlClash 只有收到流量后，才会按域名、代理组和节点选择出口。系统代理只影响主动使用代理的程序；TUN 能透明接管更多流量。

OpenVPN 通常靠路由表分流：企业网段走隧道，其他目标走默认网络。Windows 先选最长前缀，同长度再比较 Metric（跃点值）。

DNS 查询和真实连接也可能走不同路径。解析经过 VPN，不代表后续数据也经过 VPN。

安全网关还可能检查进程、控制数据或限制访问。判断它是否参与当前流量，要看驱动、服务和策略是否实际启用。

排查顺序：`git remote -v` → 代理配置 → FlClash 模式 → 系统路由 → VPN 网段与 DNS。
