# 美联储加息与 A 股

这套卡片回答两个常被混在一起的问题：美联储（Federal Reserve System，美国联邦储备系统）"加息"加的到底是什么价，以及这个价为什么会影响到中国股市。系列按"概念 → 机制 → 传导 → 误解澄清 → 实操指标"推进，共 5 张，面向有基础理财常识但不熟悉金融术语的中文读者。

## 一、加息加的是什么价

美联储加息时，并不是下达"提高存款利率"的行政命令。它调整的是**联邦基金利率（Federal Funds Rate）**的目标区间，也就是美国银行之间隔夜互相借准备金的"批发价"。这个批发价上涨后，会传导到房贷、企业贷款、信用卡和债券利率。

常见误解：美联储动的是"银行拿钱的成本"，零售端的存贷款利率是跟着变，不是被直接规定。

逻辑链：钱变贵 → 借钱的变少 → 消费与投资降温 → 通胀回落。美联储的长期通胀目标约为 2%。

## 二、存款利息为什么跟着涨

对银行来说，存款是**负债**，存款利率本质是"银行向老百姓借钱的价"，与同业拆借利率属于同一种价格的两种报价。

银行有两条进货渠道：

- **同业拆借**：银行之间互相借隔夜钱，价格围绕联邦基金利率。
- **居民存款**：向储户借钱，价格是存款利率。

两条渠道的价格必须相互贴近。同时储户有外部选项：货币基金（Money Market Fund）把钱投向短期国债和逆回购，收益紧贴政策利率。若银行不提高存款利率，存款就会搬家。因此存款利率是**被竞争逼上去的**，不是被规定的。

美联储控制的是"走廊"的三层价格：天花板是贴现窗口利率（银行直接向美联储借钱的价），中间是有效联邦基金利率（EFFR，银行间实际成交价），地板是准备金余额利率（IORB，银行把钱放在美联储账上能拿到的无风险利息）。

存贷款两端反应速度不同（存款贝塔 deposit beta < 1）：

| 端 | 反应速度 | 原因 |
| --- | --- | --- |
| 企业贷款、信用卡 | 很快 | 美国最优惠贷款利率（prime rate）通常等于目标区间上限 + 3% |
| 储蓄存款、大额存单 | 较慢、涨幅更小 | 银行不愿抬成本，赌客户懒得搬 |
| 活期、无息存款 | 几乎不动 | 本来就不付利息 |

这个错位解释了加息初期银行息差反而扩大、后期成本追上来的现象；2023 年硅谷银行危机与存款成本上升叠加持有的旧债券浮亏有关。

## 三、四条路传到中国股市

1. **中美利差收窄**：美元资产收益相对变高，部分外资减配人民币资产，北向资金流出、人民币贬值；贬值又加剧外资的汇兑顾虑。
2. **无风险利率上升**：股价等于未来利润折现，美国利率是全球定价锚之一，分母变大，估值受压；靠远期利润的成长股、科技股最敏感，现金流稳定的高股息相对抗跌。
3. **人民币汇率承压**：贬值压力大时，国内降息降准更谨慎，政策空间被压缩；反过来美联储转向时，国内空间打开。
4. **全球需求走弱**：全球借钱变贵，外需订单承压，风险偏好下降，资金撤向货币基金与美债。

一句话：美联储定的是全球资金的基准价，中国股市是全球资金池的一部分。

## 四、常见误解澄清

- **"一加息 A 股就跌"**：不成立。A 股由国内基本面、政策、流动性与估值主导；外资在 A 股流通市值中占比是个位数，主要影响情绪与边际定价。
- **"落地当天才跌"**：市场提前几个月交易预期，真正落地时常出现"利空出尽"。关键不是加没加，而是比预期更鹰（hawkish）还是更鸽（dovish）。
- **"看幅度就够"**：还要看实际利率（名义利率减通胀）与美元指数。若通胀更高，名义加息后实际利率可能仍是负的。

## 五、普通人盯三个指标

1. **美债 10 年期收益率**：全球资产定价的分母，比联邦基金利率更直接影响股市估值。
2. **美元指数（DXY）**：美元走强通常对应新兴市场资金流出。
3. **中美利差**：决定套息资金方向与人民币压力。

结构影响通常大于指数影响：外资重仓的核心资产、高估值成长板块对海外利率更敏感；内需、高股息、政策扶持方向相对独立。
