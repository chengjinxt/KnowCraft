# 跑模型前先采集什么

判断电脑能不能跑本地大模型，不能只报电脑型号。至少采集：处理器型号、架构和核心数；内存总量、可用量和插槽；图形处理器与显存；驱动和加速后端；磁盘剩余空间；页面文件或 Swap（交换空间）；推理工具版本。

运行对应脚本：

- Windows：`collect-windows.ps1`
- macOS：`./collect-macos.sh`
- Linux：`./collect-linux.sh`

脚本只读，不采集主机名、用户名、序列号、网络地址和进程列表。把生成的报告连同完整模型文件名、文件大小、上下文长度、是否使用图片输入、并发数一起带回，才能进一步判断“能否加载、速度如何、能开多长上下文”。
