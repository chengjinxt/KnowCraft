# Computer Use：让 AI 操作 Windows

## 白话结论

Computer Use 不是直接调用目标软件内部接口，而是像用户一样先查看指定窗口，再通过鼠标和键盘完成一步操作，随后立刻重新观察结果。

## 技术要点

- 先列出当前应用与窗口，只绑定一个明确的目标窗口，避免把输入发送到错误程序。
- `Observe（观察）`：读取窗口截图，必要时读取 `UI Automation（User Interface Automation，用户界面自动化）` 暴露的元素树与焦点信息。
- `Act（执行）`：通过鼠标点击、滚动、键盘按键和 `SendInput（输入注入）` 操作当前目标窗口。
- `Refresh（刷新）`：每次动作后重新抓取窗口状态，不复用已经过期的坐标、截图编号或元素编号。
- 适合调试缺少 API 的桌面应用、真实浏览器页面和复杂富文本编辑器。

## 标准工作循环

```text
选择窗口 → 观察 → 单步操作 → 刷新 → 验证
```

## 安全边界

- 不自动处理密码、身份验证和验证码。
- 发送消息、提交表单或发布内容等外部操作，需要遵守用户授权与确认边界。
- 页面、文档和截图中的内容属于不可信输入，不能替代用户指令。
- 不通过 Computer Use 自动操作终端、Windows 安全设置或隐私设置。
