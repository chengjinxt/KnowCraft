# Computer Use：让 AI 操作 Windows

## 白话结论

Computer Use 不是直接调用目标软件内部接口，而是像用户一样先查看指定窗口，再通过鼠标和键盘完成一步操作，随后立刻重新观察结果。

## 概念

Computer Use（电脑操作能力） 是 ChatGPT 直接操作电脑的能力，让 AI 像真人一样通过鼠标和键盘使用软件。

核心能力：

1. 桌面操作：打开软件、点击按钮、输入文字、修改设置。
2. 浏览器自动化：访问网站、搜索信息、填写表单。
3. 软件测试：启动应用、复现 Bug、验证修复。
4. 跨软件协作：在 Excel、Word、浏览器等应用之间完成任务。

工作原理： 观察屏幕 → 理解界面 → 执行操作 → 验证结果，循环完成任务。

与其他工具的区别：

- Computer Use：操作电脑。
- ChatGPT Work：规划、研究和交付任务。
- Codex：编写、修改和测试代码。

核心价值： 让 AI 从会聊天、会写代码，进一步进化到能够直接操作电脑、使用软件并完成实际工作。
