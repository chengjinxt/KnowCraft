# ImageGen 最终提示词摘要

四张卡片均使用 Codex 内置 `imagegen` 生成，分类为 `scientific-educational`。共同视觉要求：原创中文信息图、`3:4` 竖版、完全不透明浅米白背景、深蓝标题、青绿/蓝/黄/橙分级、圆角信息块；不使用真实商品照片、Logo、账号、二维码或水印。

## 01 — 硬件梯度

```text
重点型号：硬件从低到高
① 小米 CR6609：MT7621AT｜双核 880 MHz｜256 MB RAM｜128 MB NAND｜全千兆
② 360T7：MT7981B｜双核 1.3 GHz｜256 MB RAM｜128 MB NAND｜全千兆
③ 中国移动 RAX3000M / Me：MT7981B｜双核 1.3 GHz｜512 MB RAM｜NAND 或 eMMC｜全千兆
④ 中国移动 XR30 / RAX3000Z 增强版：MT7981B｜双核 1.3 GHz｜512 MB RAM｜eMMC 版本需核对
⑤ 京东云雅典娜 RE-CS-02：IPQ6010｜四核 1.8 GHz｜1 GB RAM｜eMMC｜1×2.5G + 4×1G
重要：硬件排名不等于购买排名
```

## 02 — 刷机支持证据分级

```text
A｜主线正式版本较明确：CR6609、RAX3000M / Me
B｜主线支持但必须核对批次：360T7
C｜主要依赖社区适配：XR30 / RAX3000Z 增强版、RAX3000QY
D｜硬件强但属于进阶选择：京东云雅典娜 RE-CS-02，主线目前以 Snapshot 为主
E｜不能只凭商品标题判断：RAX3000H、RAX1800Z、UNR030Z、SIMAX3000T、HW3000A / B1、RAX3000Z / Ze
证据强度：正式版本 > 官方 Snapshot > 持续维护的社区项目 > 卖家固件 > 口头承诺
```

## 03 — 购买建议

```text
省心自刷首选：RAX3000M / Me 原厂系统
低预算入门：小米 CR6609
愿意研究批次与救砖：360T7 或 XR30 / RAX3000Z 增强版
追求更强硬件：京东云雅典娜 RE-CS-02
买 OpenWrt 路由器，要认准确型号，不要只认品牌
对新手，成熟适配比最强硬件更值钱
```

## 04 — 品牌、渠道与具体型号

```text
中国移动型号多，就代表最好吗？
运营商批量采购，二手货源集中
同一个渠道名称下，会有不同代工厂、芯片和主板
型号后缀相近，硬件也可能完全不同
出现最多：只说明这批商品中货源多
市场流行：需要销量、装机量或调查数据，不能只凭一页商品
适合自刷：取决于准确型号、OpenWrt 支持、恢复方式和社区维护
RAX3000M / Me：软硬件与资料较均衡
小米 CR6609：预算入门
京东云雅典娜：硬件更强，但刷机更复杂
品牌相同 ≠ 芯片相同；型号相近 ≠ 固件通刷
```
