## 一句话认识 ZCode

ZCode 是面向 Agent 编程的桌面工作台。用户可以用自然语言描述目标，让 Agent 在项目中持续规划、执行和验证；官网将它定位为支持多智能体协作的“新一代氛围编程工具”。

## 卡片里的三个关键词

- `Vibe Coding（氛围编程）`：先用自然语言说明“想完成什么”，再由 AI 辅助拆解和实现；它不表示可以省略需求、测试或人工验收。
- `Multi-Agent（多智能体）`：让多个 Agent 围绕同一目标分工协作，例如分别处理代码探索、实现、测试或文档。
- `Harness（智能体工作框架）`：把模型、项目上下文、工具调用、任务状态和执行流程连接起来的一整套运行环境。白话说，模型是“大脑”，Harness 更像它工作的“操作台和工具箱”。

## 官网列出的核心能力

- `Goal（长程任务）`：持续规划、执行与验证复杂的多步骤目标。
- `Bot 控制`：可通过微信、飞书或 Telegram 远程唤起 ZCode。
- `GLM-5.3 深度集成`：面向推理、编码和多 Agent 协作优化；`GLM-5.3-Flash` 还支持截图理解、看图分析等多模态任务。

## 支持平台

- macOS：Apple Silicon、Intel。
- Windows：x64、ARM64。
- Linux：x64、ARM64；官网当前标记为 Beta。

安装时要选择与操作系统和芯片架构匹配的安装包。版本号、套餐价格和权益可能变化，以官网实时页面为准。

## 使用边界

- ZCode 可以协助理解代码、修改项目和执行验证，但 AI 生成或修改的代码仍需运行相关测试。
- 开始任务前，应让 Agent 读取仓库中的 `AGENTS.md`、开发文档和测试约定。
- 涉及删除、发布、密钥、账号、付费或外部消息时，应保留人工确认。
- `多智能体` 不等于任务一定更快；小任务可能由单个 Agent 完成得更直接。
