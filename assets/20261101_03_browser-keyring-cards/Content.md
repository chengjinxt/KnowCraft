# 浏览器密码和登录存在哪

钥匙串是操作系统给应用准备的加密保险柜，专门放密码这类机密；浏览器保存的密码默认交它保管，取用时要它先解锁。

Linux 浏览器默认走系统钥匙串；树莓派桌面会话没有已解锁的钥匙串时，启动想存密码没地方放，只能弹框问你新建一个，这是浏览器自身行为。Windows 自带凭据库，用户登录时就已经解锁，浏览器直接用，全程不用再问；不是版本区别，是系统存密码的方式不同。

basic 参数是换地方不是关功能：浏览器改用自己文件存密码，保存和自动填充照常用；代价是只做简单处理、没有真正加密，家用单人机器可以接受。保存密码和扫码登录是两套机制，前者走钥匙串或浏览器文件，后者是服务器发会话凭证，互不影响；钥匙串弹框丢不了登录状态。

扫码登录记住的是 cookie：扫码后服务器发一个会话凭证，浏览器存在配置文件夹 cookie 文件中；下次打开网站带上它，服务器认得不用再扫；有效期由服务器定，过期或清除数据就要重扫。树莓派上能接着用：只要配置文件夹还在、凭证没过期、没清数据，登录状态跨重启保留。

会丢登录状态的三种情况：开无痕窗口、退出时清除数据、换配置文件夹；钥匙串弹框点取消即可，别设密码，设了每次开机都问。
