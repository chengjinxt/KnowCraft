# 浏览器密码和登录存在哪

本组卡片讲清三个问题：浏览器保存的密码存在哪、为什么有的系统弹钥匙串框、扫码登录记住的东西存在哪。纯讲原理，不含价格、二手、购买对比内容。

## 逐卡详解

1. **钥匙串是什么**：操作系统给应用准备的加密保险柜，专门放密码这类机密。浏览器保存的密码默认交给它保管，取用时要它先解锁。
2. **树莓派上为什么弹框**：Linux 上浏览器默认走系统钥匙串；桌面会话里没有已解锁的钥匙串时，每次启动想存密码都没地方放，只能弹框问你新建一个。这是浏览器自己的行为，不是某个程序的错。
3. **Windows 上为什么不弹**：Windows 自带凭据库，用户登录 Windows 的那一刻它就已经解锁了，浏览器直接拿去用，全程不用再问。不是浏览器版本的区别，是系统存密码的方式不同。
4. **换地方不是关功能**：basic 参数让浏览器改用自己的文件存密码，保存密码和自动填充都照常用。代价是只做了简单处理、没有真正加密，能读到机器上文件的人就能看到，家用单人机器可以接受。
5. **密码和扫码是两套机制**：保存密码是浏览器帮你记账号密码，走钥匙串或浏览器文件；扫码登录是服务器发会话凭证，不走密码那条路。两者互不影响，钥匙串弹框丢不了扫码登录状态。
6. **扫码记住的是什么**：扫码后服务器发一个会话凭证，浏览器存在配置文件夹里的 cookie 文件中。下次打开网站带上它，服务器认得就不用再扫。有效期由服务器定，过期或清除浏览器数据就要重扫。
7. **树莓派上能不能接着用**：能。只要配置文件夹还在、凭证没过期、没清数据，登录状态能跨重启保留。钥匙串弹框和这事无关。
8. **什么时候会丢登录状态**：开了无痕窗口、退出时清除数据、换了配置文件夹，凭证就没了。钥匙串弹框点取消即可，别设密码，设了以后每次开机都问。

## 术语表

- **钥匙串**：操作系统提供的加密保管处，专门存放密码这类机密；取用前要先解锁。不同系统叫法不同，Windows 叫凭据库。
- **凭据库**：Windows 自带的密码存放处，随用户登录自动解锁，应用不用再单独问。
- **cookie**：网站存在浏览器里的一小段数据；扫码登录时，服务器发的会话凭证就是以这种形式存放在浏览器配置文件夹里的。
- **会话凭证**：服务器发给浏览器的身份凭证，下次访问时浏览器带上它，服务器认得就不用重新登录；有有效期，过期失效。
- **配置文件夹**：浏览器在本机保存个人数据的文件夹，包括 cookie、书签、历史记录等；换了文件夹等于换了身份，旧登录状态不在里面。
- **无痕窗口**：不保存浏览数据、关窗口即清的浏览模式，里面的登录状态关窗口就没了。
- **basic 参数**：Chromium 系浏览器启动时可选的密码存放方式，意思是改用浏览器自己的文件存密码，不走系统钥匙串。

## 适用边界

- 本卡讲的是通用原理；不同浏览器、不同系统里钥匙串、凭据库的具体叫法和表现可能不同。
- basic 参数是 Chromium 系浏览器的启动参数，其他浏览器未必有同样的开关。
- 扫码登录的有效期由各网站自己定，几天到几周都有可能；本卡不承诺具体时长。
- 本卡只讲“存在哪、为什么”，不涉及具体操作路径和账号信息。
