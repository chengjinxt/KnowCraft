# 解析、网关、隧道一次讲清

域名解析是查号：浏览器输域名，解析器查到服务器地址才能连上；解析只管查地址，不管走哪条路。114.114.114.114 国内快，个别国外域名查不到；223.5.5.5 国内快且国外兼容更好，适合主力；1.1.1.1 全球部署、隐私较好，国内不稳，适合备用。

192.168. 开头的地址（示例）有两个身份：默认网关是出门的门，解析服务器只管查域名；只改解析，出门路线不变。网关上的 OpenClash 靠解析分流：域名按规则解析，有的返回假地址再匹配代理；不用它做解析，它的解析规则和广告过滤就不生效，但流量仍走网关，按 IP 的规则还在。

Cloudflare 隧道是本机主动向外建加密通道，访客经域名和 Cloudflare 边缘进来，不用开入站端口；临时地址重启会变。隧道是请人进来，Clash 是自己出去挑路，公司 VPN 是加密回公司内网。
