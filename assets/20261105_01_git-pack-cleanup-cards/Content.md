# Git pack 本地瘦身

## `.pack` 是什么

`.pack` 是 Git 的 Packfile（对象包文件），集中保存 Commit（提交）、Tree（目录结构）和 Blob（文件内容）。它不是普通缓存，不能手工删除；配套 `.idx` 索引也不能单删，否则可能出现 Missing Object（对象缺失）。

## 为什么越来越大

Git 历史会保留旧版本。`.ipch` 智能感知预编译头缓存、`.pdb` Program Database（程序数据库）等二进制产物体积大，也不易做 Delta（差量压缩）。当前目录已删除，不等于历史已消失。

## 只清理本地

可以在新克隆或备份副本中运行 `git filter-repo`。不推送，远端和其他人不受影响；但本地提交哈希会改变，重新获取旧历史时大对象可能回来。只要最新代码时，优先使用 `git clone --depth 1`。

## 防止复发

在 `.gitignore` 中按需加入 `.vs/`、`*.ipch`、`*.pdb`。忽略规则只防止以后误提交；已跟踪文件要先取消跟踪，历史仍大才需要重写。
